## `batcat`

Shows a file like cat, but with syntax highlighting and line numbers

```bash
batcat script.sh
```

## `js-beautify`

Formats minified JavaScript or JSON so it's readable (line breaks and indentation)

```bash
curl -s -X GET https://example.com/bundle.js | js-beautify
```
